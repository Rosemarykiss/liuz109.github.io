Midterm Reflection

Looking back at my projects so far, I noticed that I enjoy using colors, images, and typography to create different visual styles. Each project has a different theme, so I try to design each website in a way that fits its content. For example, my MoMA project focuses more on images and layout, while my recipe project uses brighter colors, playful fonts, and rounded shapes.

Even though my projects look different, I usually pay attention to how images and text work together. I like keeping my layouts organized while also adding some fun details.

So far, I have learned more about HTML and CSS, especially how to use different layouts, positioning, and responsive design. I also learned that small changes in spacing, font size, and alignment can make a big difference.

For my future projects, I want to experiment more with interactive elements, animations, and different ways to organize content. I hope to make my websites not only look interesting but also easy to use.
